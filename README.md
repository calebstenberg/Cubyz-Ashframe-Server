# Cubyz-Ashframe-Server
Custom modification, that is used to run Ashframe server.


At the moment it features new commands, I will update this later.

/**home add (name)** (set's your current location as your new home)
/**home** (teleports you home)
/**tpa (@userID)** (request a tp to a player)
/**tpaccept** (accepts teleport request)
/**playtime** (show's your playtime on the server)
/**playtime list** (shows the server leader-board)
/**afk** (let everyone know you are afk)
/**avatar (base:nameofskin)** (change your character model)
/**players** (show's all online players)
/**spawn** (tp's you to spawn)
/**back** (tp's you back to your last position)

# ADMIN
/**prefix add @ID (Admin)** (allows to add prefix to anyone)
/**prefix remove @ID** (allows to add prefix to anyone)
